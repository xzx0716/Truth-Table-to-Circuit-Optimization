# 构造与版本对应

本实验从 GitHub 的 main 提交 `585b22a607fb6973d898b9240e5ab51739690676` 开始，复用原求解器的网表、门库、面积与时序计算、预算和代数改写。构造参数只依赖用例内容。实验开关使用同一个可执行文件和原来的两个路径参数。

| 配置 | 如何产生初始电路 |
|---|---|
| github | 运行该提交的 synthesize，取它选出的一个电路 |
| historical-adaptive | 接回历史版的条件逆序策略。先做正序，根据预算和正序图大小决定是否加试逆序，再按原版的宽度、映射和面积恢复规则选网表 |
| forward-sop / reverse-sop | 按输入编号正序或逆序拆分。每层把两条分支写成两个与项，再用或门合并 |
| influence-sop | 翻转各输入，观察多少输出位跟着变化。优先拆分变化多的输入，最多取 512 行，用固定随机种子 |
| forward-pos | 固定正序，把同一层的两个分支展开成两个或项，再用与门合并 |
| forward-demorgan | 对正序积之和初始电路应用历史的正负极性映射，用门库的面积和延迟决定哪里使用反相 |
| forward-top3 / reverse-top3 | 首次展开最多三个变量。合并通向相同剩余函数的条件，下层恢复逐变量展开 |
| forward-rec3 | 在后续各层继续每次展开最多三个变量，合并重复的剩余函数 |
| forward-adaptive3 | 每个剩余函数从宽度 1、2、3 中选择。用各剩余函数出现的次数和门库成本估计分组效果 |

历史条件逆序代码来自 `outputs/stage1-variable-order/solver.cpp`，SHA-256 为 `19d3824c52e9b55f06df4c123f83b8485b55012607743487d5c2515a17398f68`。移植在相同的 macOS 编译器上对所有 25 个公开用例逐字节复现了历史源码输出的网表。历史 Pareto 版单文件 SHA-256 为 `a26bba783aaacc1617683a48705e22db59fdb38765d54466ffbf3037533b5bd5`。GitHub 原版可通过上面的提交重新取得。

讲义的双输出样例在测试中独立按真值表验证。逆序逐变量展开产生了信号 4 = OR2(1,2)、信号 5 = AND2(3,4)，输出为 4、5。该共享电路面积 10，延迟 5。
