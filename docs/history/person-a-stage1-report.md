# Stage 1：甲的方法、实验与结果报告

截止要求：2026-11-19 23:59；本报告版本为甲已完成的可提交候选。
当前代码版本与交接定位见 `docs/Stage1-Handoff.md`。本报告不声称乙的新增算法已完成。

## Method

### 输入、功能与门库

每次程序读取一个完整多输出真值表，二进制输入顺序中 x0 是最高位。门库仅为 AND2、OR2、NOT，使用各 case 给出的正面积和延迟。支持常数0；常数1由 NOT 0 生成。输出按拓扑顺序连续编号，末行是全部输出信号。可直接连接输入或常数。

### 初始电路构造

以队友交接版为基础：Shannon 恒等式 f=(NOT x AND f0) OR (x AND f1) 将真值表递归分解成约简 BDD；相同分支省去变量，相同子函数跨输出共享，最后三个输入的八位函数模式缓存。当前默认变量顺序固定。

顶部若干层按相同剩余子函数合并选择条件，复用条件与门，组合早到信号以减少晚到信号经过的门数。尝试直接映射、德摩根替换、不同 MUX 展开和自适应顶部宽度。平衡只展开私有同类门，保护共享。

重映射从输出预算反推节点最晚到达时间，在正/反极性的候选实现中以面积流作启发式选择；生成完整网表后以真实指标验收。沿用目标预算、快速方案预算和中间预算。面积流不等于全局精确面积，BDD 节点也不等于物理门。

### 甲的新增默认优化

默认 sweep 在已有电路上重复批量代数扫描：吸收、因式提取及 AND/OR 对偶、重结合、德摩根等。每个替换检查局部边界所有输入组合；在一轮共享 DAG 重建中合并多处局部改写。局部面积使用表达式上界与可删除私有锥比较；最终仍以完整电路计算为准。

每轮去除无用门、计算真实面积和最大输出到达时间。只有两项均不恶化才继续行走；所有候选仍交给归档统一筛选。结构不变、最多16轮或公共预算截止时停止。该路径避免每个小修改都重建全图，实际优于把高成本搜索默认全部打开。

### 完整研究搜索

独立研究配置实现了因式提取/分配展开、吸收、重结合、正反变换；不同边界规模的 Cut 枚举和三种 Shannon 重综合；贪心、束搜索、模拟退火、多起点。局部真值表和模板缓存复用，同一轮廉价代数改写先覆盖全图，再给昂贵 Cut 分配时间。

贪心选择改善的加权能量；束搜索保留可配置数量的不同状态；退火允许抽样上坡转移；多起点使用不同遍历顺序与面积/延迟权重。它们是启发式搜索，不是完整 Pareto 动态规划。

SAT 和 MILP 为真实的单输出有界精确综合，显式编码门型、前向连接、全部真值表行、面积和延迟。保存74次规模/公开电路局部函数实验。SAT完成25个局部有界最优证明，MILP完成20个，5个保留可行解但未证明。另离线生成覆盖16个二输入函数的33个通用模板并接入研究 Cut 替换；这些模板与公开用例无关，最终 C++ 无求解器依赖。只有限定门数和延迟范围内的最小面积得到证明，未证明完整 case 全局最优，也未证明同面积下最小延迟。

### 两层 Pareto 和最终选择

研究电路归档保留实际 area-delay 非支配点，包括超标点。最终仍优先选择达标候选；达标点中最小化 max((A-Amin)/max(1,Amin),(D-Dmin)/max(1,Dmin))，平手依次比较相对损失和、面积。无达标解时按延迟、面积、门数选择。该公式是内部政策，不是官方评分公式。基线内部重映射的部分候选仍受原 Frontier 筛选，因此没有穷尽全部前沿。

策略层比较不同完整运行配置的 area、delay、总 runtime。运行中发现某候选的累计耗时不当成电路属性。三目标前沿与重复计时范围单独记录，不推断未知班级分数。

### 正确性与资源管理

BDD 分解、门映射和代数规则由布尔恒等式保持功能；局部替换再对全部独立边界赋值检查。只连接先前节点以避免环，完整输出保持全部输出函数。无用门在写出前删除，共享门面积只计一次。

Runtime 从 main 开始计时，包括读取、搜索、写出和退出，排除 evaluator 正确性检查。公共预算保留 max(5ms,10%正限制) 给输出，局部搜索默认工作窗100ms，并与课程截止取早者。长搜索循环检查预算；实际操作耗时更新单位成本估计，并加1.5余量。冷启动扫描成本经公开输入诊断校准。正RAM限制下检查Linux进程RSS并预留空间。

这属于启发式资源管理：读取、首次基础构造、部分平衡/重映射、归档复制和指标整理不能完全中断，因此不保证任意紧限制都通过。真值表至少需要 O(m*2^n) 输入处理，BDD可能指数增长，Cut和搜索状态也可能指数增长。没有省略这些成本。

### 与冻结交接版比较

面积总和728930→728872，减少58（约0.00796%），9例面积下降，所有25例delay不变，其他16例A/D不变。该总和仅作描述，不是总分。收益较小，不能写成巨大优化或全局最优。

同一轮交替五次的校准前基线/默认策略实验中，先取每例中位数再跨25例取中位数为15.986ms→25.616ms；说明甲默认增加了计算成本。校准后单独复测中该统计为28.640ms；不得把跨实验机器波动误写成算法变化。完整三目标表保留基线：并非全部case上默认策略都在三项支配基线。

### 完整研究与失败备选

- screen：所有四种策略及代数单项均25/25，但收益/成本较差，促使实现批量扫描、缓存和分时。
- scale：Cut2/4/6/8/10和portfolio实际全量尝试；原始限制下分别19、18、18、18、12、12例通过。失败主要为TIME_LIMIT，原始失败记录全部保留，不能将成功子集面积和当作全25例结果。
- research-deep：仅将独立副本runtime字段放宽至10000ms，函数/门成本/目标不变；深度配置25/25，面积总和728816，case023从272/20到259/20，但运行常约3秒。这些是研究潜力，不是原始限制下可提交成绩。
- formal：原始限制下baseline/algebraic/adaptive各五轮全部通过；复杂配置部分A/D随截止位置变化，报告保留每轮原始数据，不用虚构稳定单点。
- exact：精确研究与通用模板完成后已接入在线研究Cut；未将外部SAT/MILP加入默认执行路径。

### 独立验证

六种配置（baseline、sweep、greedy、beam、anneal、multistart）各400项小规模测试通过；覆盖1–3输入全部单输出函数、常量、直连、共享、互补、多输出、随机及资源字段。局部模块510个候选对全部输入独立仿真，含收敛、策略差异、共享和截止。早期局部实现另完成ASan/UBSan检查。

固定新种子生成12/16/20输入的结构化、变量置换和随机门网络，共9例，默认与研究配置均9/9官方PASS，默认输出还经独立位并行仿真全行验证。它们是已知随机电路生成的函数，并不代表均匀随机大真值表或隐藏集性能。

初次新例目录文件命名不匹配evaluator的case_*.txt规则，导致运行器错误，记录在heldout目录；改为合法名称后heldout-fixed验证通过。没有将此工具错误当作求解器逻辑失败。

### runtime预测结果

扫描初始冷启动28次中25次低估，实际/预测中位数10.15；校准为4e-4ms/门后，同公开输入诊断28次中4次低估，中位数0.674、最大1.755。该对照在调参输入上完成，存在机器负载差异，不能声称独立泛化。其他操作仍有较大尾部误差；诊断计时嵌套不可相加。见cost-model两目录与runtime-model说明。

## 局限与下一步

当前默认保持基线delay，面积下降有限。复杂搜索在紧限制下不可全部启用；运行时间预测未给出最坏保证。下一步按改善概率/成本调度区域，增加候选去重和共享感知增量指标；SAT扩大有界证明并改善MILP对称性；乙提供多方案映射、跨输出重代入、变量顺序及分组探索后，按公共接口做组合消融。全局最优、乙的新算法、Stage2/隐藏case测试均未完成，不能写为已完成。
